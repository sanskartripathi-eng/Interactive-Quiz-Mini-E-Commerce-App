# Brew & Co. – Mini E-Commerce App

A beginner-friendly product catalog with a working shopping cart and checkout preview, built with plain HTML, CSS and JavaScript (no frameworks).

## Features
- Products rendered dynamically from an array of JS objects
- Category filters
- Add to cart, increase/decrease quantity, live item count and total (in INR, Indian number format)
- Slide-in cart drawer
- Modal checkout preview with subtotal, 5% GST and grand total
- Responsive layout with automatic light/dark mode

## Run locally
Open `index.html` in your browser. No build step or install needed.

## Project structure
```
index.html   – page structure
style.css    – styling, themes, responsive layout
script.js    – product data, cart logic, rendering, modal
```
